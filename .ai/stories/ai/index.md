# AI Platform

This file is the index or main file that represents the overall goal and objective of what we want to build. An ai platform that I can use.

## Overview

We want to build our own version of an ai platform. At this point its not for external or open source use yet. Mainly driven for personal use and instead of reinventing the wheel were just using a combination of tools, services, etc...together and building around it.

### Inspiration

Here is an example but they made it for open source public use and they took a different approach where they are building custom solutions and re inventing the wheel.

Repo: https://github.com/cnoe-io/ai-platform-engineering
Docs: https://cnoe-io.github.io/ai-platform-engineering

We can decide what to build vs what to use and I think it will be a combination of both. However, for example we have N8N, we dont need to build a UI for agent orchestration...

However I think this can be a big source of inspiration that we pull from.
