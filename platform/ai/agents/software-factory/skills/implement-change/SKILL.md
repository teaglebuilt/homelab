# Implement change
1. Read approved issue/design, existing code and repo-specific instructions.
2. Plan smallest patch and test changes, then change only the requested repository.
3. Use feature branch; preserve existing file conventions.
4. Run tests through an authorized tool or CI. Do not invent success.
5. Open PR only with approval and proper tool credentials; provide PR/commit.
6. If no writable Git/checkout interface, return a proposed patch and BLOCKED.
