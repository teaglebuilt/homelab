# Test change
1. Read acceptance criteria and changed files.
2. Identify test commands in repository configuration; don't invent commands.
3. Run via authorized CI/test sandbox when available.
4. Record exact command/job, exit result, and failure details.
5. Mark unexecuted test plans as PROPOSED, not PASS.
